<h1>Heart Failure Prediction</h1>
<ul>
  <li>Developed and compared machine learning models for predicting heart disease using clinical and demographic features.</li>
  <li>Achieved 84.75% accuracy with Gradient Boosting after comparing multiple machine learning algorithms.</li>
  <li>Performed exploratory data analysis, preprocessing, and correlation matrix visualization to identify key feature relationships.</li>
  <li>Tuned and evaluated models using hyperparameter optimization, ROC curve analysis, and confusion matrix to improve predictive accuracy.</li>
</ul>
